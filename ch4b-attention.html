Chapter 04b · a refresher, using MIRA's own tokens

How an attention block actually works

Chapter 04 showed where attention sits in MIRA. This page opens one attention layer and runs it step by step, with real arithmetic on real MIRA latent tokens. You'll see every matrix the layer builds, then how MIRA stacks the pieces into a full block: heads, grouped keys, rotary positions, the space/time reshaping trick, the gate and the MLP.

1 · The one-paragraph version

An attention layer takes a set of tokens and lets every token pull in information from the others, weighted by relevance. Each token is projected three ways: a query (what it is looking for), a key (what it offers) and a value (what it hands over). Relevance is the dot product of one token's query with every key. A softmax turns those scores into weights that sum to 1. The output is the weighted average of the values, which is added back onto the token.

Q = X·WQ   K = X·WK   V = X·WV
S = Q·Kᵀ / √dhead   # every query vs every key
S = S + mask   # −∞ where not allowed (time layers)
A = softmax(S) row-wise   # each row sums to 1
O = A·V   # weighted average of values
X ← X + gate ⊙ (O·WO)   # residual add

3 · Many heads, fewer keys (multi-head + GQA)

One head can only look for one kind of relevance at a time. So MIRA splits each token's 4096 numbers into 32 heads of 128. Each head has its own slice of WQ, WK, WV and computes its own attention pattern, like heads 1 and 2 above. The 32 outputs are concatenated back to 4096 numbers and mixed by the output matrix WO.

Grouped-query attention (GQA): MIRA keeps 32 query heads but only 8 key/value heads. Each group of 4 query heads shares one key and one value. The queries still look for different things, but there are 4× fewer keys and values to compute and, crucially, to store in the KV cache while streaming.

4 · Where am I? Rotary position embedding (RoPE)

The dot product q·k knows nothing about where tokens are. MIRA adds position by rotating queries and keys before the dot product: a token at position m has pairs of its numbers rotated by an angle proportional to m.

Rotating q by angle m·θ and k by n·θ changes their dot product only by the difference (m − n)·θ. So attention sees relative offsets ("two cells to the left", "0.3 s earlier"), never absolute ones. MIRA uses this in three directions: row and column inside the grid (spatial RoPE), and time in seconds (temporal RoPE).

Because nothing is tied to absolute positions, the same weights work on a 9-row single-player grid and on the 36-row four-player grid. That is how the multiplayer model is warm-started from the single-player one.

6 · The whole block

Attention is half of a block. Around it are normalisation, a gate, the per-token MLP, and the residual stream: each sub-layer reads the tokens and adds a correction instead of replacing them. One MIRA block, in order:
